# jMidi 1.0.0

## Highlights
- Dedicated MIDI In / Out monitoring screen.
- Input and output connection information.
- Live MIDI message counters and last-message details.
- Separate receive and successful-send event logs.
- Queue depth and dropped-event diagnostics.
- Existing MIDI editing, timing, arrangement, accompaniment and MIDI Care tools retained.

## Validation
67 automated tests passed locally. Python compilation and archive integrity checks passed. GUI runtime, Windows executable and physical hardware acceptance remain to be completed on Windows with MIDI devices.
